# FaceAttendEDU-RAPS

Paquete de evidencias de aprendizaje (RAPS) del proyecto **FaceAttend EDU**, sistema de gestión de asistencia con reconocimiento facial desarrollado en el programa Tecnólogo en Análisis y Desarrollo de Software (ADSO) del SENA, ficha 3145556.

[English version](README_EN.md)

## Propósito

Este repositorio reúne los entregables formales que el programa ADSO pide para evaluar el proyecto: requisitos, análisis, propuesta técnica, diseño, artefactos de código, pruebas, implementación, acciones de mejora, manuales y el artículo del proyecto. Cada carpeta corresponde a un entregable y cada documento existe en español y en inglés.

No contiene código fuente. El código y la documentación de trabajo del equipo viven en otros repositorios (ver [Relación con otros repositorios](#relación-con-otros-repositorios)).

## Convención de idiomas

- En las carpetas `01` a `10`, cada entregable tiene una subcarpeta `es/` (español) y otra `en/` (inglés) con el mismo contenido.
- En `Anexos/01-Historias_de_usuarios`, las subcarpetas usan mayúsculas: `ES/` y `EN/`. Los archivos en español se llaman `Historia_de_usuario.md` y los de inglés `user-stories.md`.
- `Anexos/02-Mapa_navegación` tiene un único archivo (`navigation-map.md`), escrito en español; no tiene versión en inglés.
